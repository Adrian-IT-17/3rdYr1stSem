## Q1

**Question:** A business analytics team proposes a dashboard for overdue accounts. Which statement best expresses expected value?

**Type:** single

**Options:**

- A. Managers will receive a modern-looking home page
- B. Collection officers can identify priority accounts earlier and reduce the average time to first action
- C. The dashboard will use the newest visualization library
- D. The project will contain twelve charts and three filters

**Answer:** B

**Explanation:** Expected value describes the measurable benefit a system is expected to provide. Identifying priority accounts earlier and reducing the time to first action directly describes a useful business outcome.

## Q2

**Question:** A team combines Scrum events, a formal architecture review, and a controlled release checklist. What makes this combination defensible?

**Type:** single

**Options:**

- A. Every project must use the same combination
- B. The practices are popular in different industries
- C. Each practice addresses a documented project condition, with clear boundaries, handoffs, owners, and risks

**Answer:** C

**Explanation:** A hybrid combination of practices is defensible when each practice addresses a specific project need and the team clearly defines responsibilities, boundaries, handoffs, and risks.

## Q4

- B. Build every possible feature before the first review

## Q7

## Q11

**Question:** A team creates an Ishikawa diagram for delayed permit approval. How should the branches in the diagram be treated?

**Type:** single

**Options:**

- A. As proof that every listed cause is equally important
- B. As hypotheses that must be tested against credible evidence
- C. As a substitute for stakeholder and process evidence
- D. As final requirements ready for programming

**Answer:** B

**Explanation:** An Ishikawa or fishbone diagram identifies possible causes of a problem. These possible causes are hypotheses and must be investigated and supported by evidence before they are accepted as actual causes.

## Q12

**Question:** An online course platform detects that weekly completion has fallen below 70% and automatically alerts the instructor to schedule a support session. Which systems principle is most clearly demonstrated?

**Type:** single

**Options:**

- A. Feedback is compared with an expected level to support corrective action
- B. Outputs are treated as inputs without any control rule
- C. A subsystem can operate without a purpose or environment
- D. The system boundary expands whenever performance declines

**Answer:** A

**Explanation:** The system compares actual performance with an expected level. When performance falls below the threshold, feedback triggers corrective action, demonstrating a feedback-and-control mechanism.

## Q13

**Question:** A mobile attendance proposal records students' precise location every minute, including outside class hours. Attendance can be verified using a check-in event during the scheduled class. What is the most responsible recommendation?

**Type:** single

**Options:**

- A. Hide the tracking practice in the terms and conditions
- B. Retain continuous tracking because more data is always better
- C. Allow instructors to download all location histories to personal devices
- D. Collect only the check-in data needed for attendance, define retention, and obtain appropriate notice or consent

**Answer:** D

**Explanation:** Data collection should be limited to what is necessary for the stated purpose. If a class check-in can verify attendance, continuous location tracking collects unnecessary information and creates additional privacy and security risks.
