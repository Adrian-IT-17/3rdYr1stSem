# IT0035 Formative Assessment 1

## Q1
**Question:** Operating system is what type of software?
**Type:** single
**Options:**
- Utility
- Program
- Application
- System
**Answer:** System
**Explanation:** An operating system is system software because it manages computer hardware and software resources and provides services for application programs.

## Q2
**Question:** Execute user programs and make solving user problems difficult is one of the goals of OS.
**Type:** single
**Options:**
- True
- False
**Answer:** False
**Explanation:** One of the goals of an operating system is to execute user programs and make solving user problems easier, not difficult.

## Q3
**Question:** Windows 10 is an example of hand-held operating system.
**Type:** single
**Options:**
- True
- False
**Answer:** False
**Explanation:** Windows 10 is primarily a desktop operating system and is not classified as a hand-held operating system.

## Q4
**Question:** Which is not an example of system software?
**Type:** single
**Options:**
- NotePad
- Windows 10
- MS word
- Linux
**Answer:** MS word
**Explanation:** MS Word is application software designed for creating and editing documents, while Windows 10 and Linux are operating systems. Among the choices, MS Word is the intended answer.

## Q5
**Question:** It is the central part of an OS which manages system resources and is always resident in memory.
**Type:** single
**Options:**
- Kernel
- BIOS
- IOS
- Bootloader
**Answer:** Kernel
**Explanation:** The kernel is the core component of an operating system. It manages system resources such as the CPU, memory, and devices and remains resident in memory while the system is running.

## Q6
**Question:** This refers to a text-based type of user interface.
**Type:** single
**Options:**
- Graphical User Interface
- Batch-based Interface
- Command Line Interface
- Menu-based Interface
**Answer:** Command Line Interface
**Explanation:** A Command Line Interface (CLI) is a text-based interface that allows users to interact with a computer by entering commands.

## Q7
**Question:** Operating system controls and coordinates the use of the hardware among the various application programs for the various users.
**Type:** single
**Options:**
- True
- False
**Answer:** True
**Explanation:** An operating system manages and coordinates hardware resources so they can be used efficiently by different applications and users.

## Q8
**Question:** A portion of main memory is dedicated to OS
**Type:** single
**Options:**
- True
- False
**Answer:** True
**Explanation:** A portion of main memory is reserved for the operating system so that its essential components and services can remain available while the computer is running.

## Q9
**Question:** _________ is a defense of the system against internal and external attacks.
**Type:** single
**Options:**
- Quarantine
- Protection
- Defense
- Security
**Answer:** Security
**Explanation:** Security refers to defending a computer system against internal and external attacks and other threats.

## Q10
**Question:** ________Operating System is an OS intended to serve real-time systems/applications that process data as it comes in, mostly without buffer delay.
**Type:** single
**Options:**
- Handheld
- Distributed
- Real Time
- Network
**Answer:** Real Time
**Explanation:** A Real-Time Operating System (RTOS) is designed to process data and respond to events within strict timing requirements, typically with minimal delay.

## Q11
**Question:** Hardware interrupt is a signal created and sent to the CPU that is caused by some action taken by a software.
**Type:** single
**Options:**
- True
- False
**Answer:** False
**Explanation:** A hardware interrupt is generated by a hardware device or hardware event. An interrupt generated through software is considered a software interrupt.

## Q12
**Question:** A type of interrupt handling in which the OS sends signal to each devices asking if they have a request.
**Type:** single
**Options:**
- Vectored interrupt system
- Forwarding
- Polling
- Calling
**Answer:** Polling
**Explanation:** Polling is a method in which the system checks devices one by one to determine whether any of them requires service or has a pending request.

## Q13
**Question:** A type of multiprocessing in which a boss processor controls the system and the other processors either look to the boss for instructions or have predefined tasks.
**Type:** single
**Options:**
- Asymmetric
- Systematic
- Symmetric
- Synchronous
**Answer:** Asymmetric
**Explanation:** In asymmetric multiprocessing, one processor acts as the master or boss processor and controls the system, while the other processors perform assigned or predefined tasks.

## Q14
**Question:** Operating systems made available in source-code format which has copyleft is called __________________
**Type:** single
**Options:**
- Proprietary OS
- Open-source OS
- BIOS
- Free OS
**Answer:** Open-source OS
**Explanation:** An open-source operating system makes its source code available for users to inspect, modify, and distribute according to its license. Copyleft licenses can require modified versions to remain available under similar licensing terms.

## Q15
**Question:** Buffer is a region of memory used to permanently hold data while it is being moved from one place to another.
**Type:** single
**Options:**
- True
- False
**Answer:** False
**Explanation:** A buffer temporarily, not permanently, holds data while it is being transferred from one place or device to another.

## Q16
**Question:** A software-generated interrupt caused either by an error or a user request is called _______________________
**Type:** single
**Options:**
- Trap
- Lost interrupt
- Interrupt
- System call
**Answer:** Trap
**Explanation:** A trap is a software-generated interrupt that can occur because of an error or a request made by a program or user process.

## Q17
**Question:** Software as a service(SaaS) provides one or more applications available via the Internet
**Type:** single
**Options:**
- True
- False
**Answer:** True
**Explanation:** Software as a Service (SaaS) provides software applications to users over the Internet rather than requiring the applications to be installed and maintained locally.

## Q18
**Question:** Platform as a service(PaaS) provides software stack ready for application use via the Internet.
**Type:** single
**Options:**
- True
- False
**Answer:** True
**Explanation:** Platform as a Service (PaaS) provides a ready-to-use software platform or stack over the Internet that developers can use to build, deploy, and manage applications.

## Q19
**Question:** _____interrupt is a signal created and sent to the CPU that is caused by some action taken by a hardware device.
**Type:** single
**Options:**
- HardWare
- System
- Software
- Lost
**Answer:** HardWare
**Explanation:** A hardware interrupt is a signal sent to the CPU as a result of an event or action involving a hardware device.

## Q20
**Question:** It alerts the processor temporarily to a high priority process requiring interruption of the current working process and then return to its previous task.
**Type:** single
**Options:**
- Disturb
- Link
- Bug
- Interrupt
**Answer:** Interrupt
**Explanation:** An interrupt alerts the processor that an event requires immediate attention. The processor temporarily suspends its current task, handles the interrupt, and then can return to the previous task.
